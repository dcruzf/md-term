# Color themes

md-term now ships with six themes: `phosphor`, `amber`, `ice`, `mono`,
`dracula` and `paper`. The theme of a site is one line in `md-term.toml`:

```toml
theme = "amber"
```

Individual colors can be adjusted in the `[colors]` table, and visitors can
switch themes from the shell with `theme <name>`.

It is all described in [Themes and colors](../guide/themes.md).
