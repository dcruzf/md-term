# Temas de cores

O md-term agora vem com seis temas: `phosphor`, `amber`, `ice`, `mono`, `dracula` e
`paper`. O tema do site é uma linha no `md-term.toml`:

```toml
theme = "amber"
```

Dá para ajustar cores isoladas com a tabela `[colors]`, e o visitante pode
trocar de tema pelo shell com `theme <nome>`.

Tudo está descrito em [Temas e cores](../guia/temas.md).
