# md-term

A static site generator that serves markdown through a terminal interface.
Think of mkdocs, except that visitors browse the knowledge base or blog with
`ls`, `cd`, `cat` and `grep`.

- Every `.md` file becomes a complete HTML page: it works without JavaScript,
  can be indexed and every link can be shared.
- With JavaScript the page gains a prompt with history, tab completion and
  full-text search. Everything that is listed is clickable too.
- Posts with dates, tags and an RSS feed.
- Obsidian-friendly: `[[wikilinks]]`, embeds and callouts work, and
  `md-term build --watch` keeps a site in step with a vault folder.
- Rich markdown: alerts, LaTeX formulas rendered at build time, Mermaid
  diagrams, footnotes, task lists and highlighted code.
- Optional Python in the browser (a REPL and runnable code blocks),
  downloaded only when a visitor uses it: Monty (light) or Pyodide (full
  CPython, with packages).
- Six color themes (`phosphor`, `amber`, `ice`, `mono`, `dracula`, `paper`)
  and a palette you can configure in `md-term.toml`.

## Usage

```bash
pip install md-term     # Python 3.11+
md-term new my-site     # creates md-term.toml and docs/
cd my-site
md-term serve           # http://127.0.0.1:8000/, rebuilds on save
md-term build           # writes the static site to site/
```

The full documentation lives in [docs/](docs/index.md), which is also the
example site: run `md-term serve` at the root of this repository to read it
in the terminal.

## Development

```bash
uv sync
uv run md-term serve                  # also watches templates and assets
uv run pytest                         # the generator
node --test "tests/js/*.test.mjs"     # the browser shell
uv run ruff check . && uv run ruff format --check .
```

The generator is in `src/md_term/` (Python). The front end is plain
JavaScript and CSS in `src/md_term/assets/`, with no build step: `shell.js`
and `vfs.js` never touch the DOM and are tested with Node; `term.js` drives
the interface.

The glue code of the Monty interpreter is in `src/md_term/runtimes/monty/`
and is generated by `tools/monty-glue` (`npm install && npm run build`). Run
it again when bumping the Monty version.
